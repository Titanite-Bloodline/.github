# .github

This repository holds the Titanite Bloodline's GitHub profile page. Edit `profile/README.md`
to change what visitors see at https://github.com/Titanite-Bloodline, and `profile/banner.svg`
to change the banner.

`discord/` holds the header images for the Titanite Bloodline Discord's panels (rules, roster,
resources, tickets, volunteer). Chancery's ticket panel presets and webhook tools link to them here,
so keep the file names stable.
